**Neon Sunset Cover Studio** — a web app that turns a person's photo plus a caption into GTA-poster-style multi-panel cover art with a Vice City sunset / neon grade. It runs entirely offline in the desktop browser: no uploads, no account, no server calls. Export the finished cover as a PNG in 1080×1080 (square), 1080×1350 (portrait), or 1920×1080 (landscape).

## Features

- Upload a photo (or try a built-in sample) and add a caption
- GTA-poster-style multi-panel layout with a Vice City sunset / neon grade
- Live preview in the browser; everything processed locally
- One-click PNG export in three sizes: 1080×1080, 1080×1350, 1920×1080

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or serve the `app/` directory with any static file server and open `index.html`.
